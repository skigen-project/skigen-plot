# PlotView

The main widget for 2D and 3D plotting. Inherits from `QRhiWidget` and provides hardware-accelerated rendering via Vulkan, Metal, or Direct3D 12.

## Synopsis

```cpp
namespace Skigen::Plot {

class PlotView : public QRhiWidget {
public:
    PlotView(QWidget* parent = nullptr);

    // 2D line plot
    template <typename DerivedX, typename DerivedY>
    SeriesHandle plot(const Eigen::MatrixBase<DerivedX>& x,
                      const Eigen::MatrixBase<DerivedY>& y,
                      const PlotStyle& style = {});

    // 2D scatter plot
    template <typename DerivedX, typename DerivedY>
    SeriesHandle scatter(const Eigen::MatrixBase<DerivedX>& x,
                         const Eigen::MatrixBase<DerivedY>& y,
                         const PlotStyle& style = {});

    // 2D histogram
    template <typename Derived>
    SeriesHandle hist(const Eigen::MatrixBase<Derived>& values,
                      int bins = 0,
                      bool density = false,
                      const PlotStyle& style = {});

    // 2D stem plot
    template <typename DerivedX, typename DerivedY>
    SeriesHandle stem(const Eigen::MatrixBase<DerivedX>& x,
                      const Eigen::MatrixBase<DerivedY>& y,
                      const PlotStyle& style = {});

    // Series lifecycle
    bool updateSeriesData(SeriesHandle handle, const auto& x, const auto& y);
    bool setSeriesStyle(SeriesHandle handle, const PlotStyle& style);
    bool setSeriesVisible(SeriesHandle handle, bool visible);
    bool containsSeries(SeriesHandle handle) const;
    bool removeSeries(SeriesHandle handle);

    // 3D point cloud
    template <typename Derived>
    void pointCloud(const Eigen::MatrixBase<Derived>& vertices);

    // Appearance
    void setBackgroundColor(const Eigen::Vector4f& rgba);
    void setLegendVisible(bool visible);
    bool legendVisible() const;
    void setLegendPosition(LegendPosition position);
    LegendPosition legendPosition() const;

    bool setXLimits(float left, float right);
    bool setYLimits(float bottom, float top);
    std::pair<float, float> xLimits() const;
    std::pair<float, float> yLimits() const;
    void resetXLimits();
    void resetYLimits();
    void resetAxisLimits();

    // 3D camera
    void setCamera(const Camera3D& camera);

    // Export
    bool savePng(const QString& path, int width, int height);
};

} // namespace Skigen::Plot
```

## Description

`PlotView` is the central class of SkigenPlot. It accepts Eigen matrix expressions directly — no manual data conversion needed. Data is interleaved into GPU vertex buffers and rendered using Qt's RHI abstraction layer.

Line, scatter, histogram, bar, horizontal-bar, filled-area, step, error-bar,
stem, and quiver creation returns an opaque `SeriesHandle`. Handles remain stable
when other series are removed. Mutating or removing an invalid, stale, or
foreign handle returns `false` and leaves the view unchanged. Creation with
insufficient input returns an invalid handle.

A stem plot's vertical geometry and marker tips share one handle. Data, style,
visibility, and removal operations therefore apply to the complete composite.

Set a non-empty `PlotStyle::label` and call `setLegendVisible(true)` to show a
theme-aware legend. `LegendPosition::Auto` selects the least occupied plot
corner; `UpperLeft`, `UpperRight`, `LowerLeft`, and `LowerRight` provide fixed
placement. Hidden and unlabelled series are omitted.

Axis limits can be controlled independently. Setters reject non-finite or
equal endpoints without changing the current view. Reversed endpoints are
preserved and invert that axis; reset methods restore autoscaling for one or
both axes.

Scatter styles support `MarkerShape::Circle`, `Square`, `Triangle`, `Plus`,
and `Cross`. Closed shapes can be filled or hollow, and all marker shapes use
`PlotStyle::pointSize` for sizing.

See the [Line Plot](../guide/line-plot) and [Scatter Plot](../guide/scatter-plot) guides for usage examples.
