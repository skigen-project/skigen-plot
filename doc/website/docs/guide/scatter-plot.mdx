# Scatter Plot

Render a 2D scatter plot of discrete data points. Uses the same rendering pipeline as line plots with point topology.

## API

```cpp
template <typename DerivedX, typename DerivedY>
SeriesHandle PlotView::scatter(const Eigen::MatrixBase<DerivedX>& x,
                               const Eigen::MatrixBase<DerivedY>& y,
                               const PlotStyle& style = {});
```

## Methods

| Method | Description |
|--------|-------------|
| `scatter(x, y, style)` | Add scatter data and return its stable handle |
| `setSeriesStyle(handle, style)` | Update colour, marker, size, fill, and label |
| `setSeriesVisible(handle, visible)` | Show or hide one scatter series |
| `removeSeries(handle)` | Remove one scatter series |
| `setBackgroundColor(rgba)` | Set viewport background colour |

`PlotStyle::marker` accepts `MarkerShape::Circle`, `Square`, `Triangle`,
`Plus`, or `Cross`. Circle, square, and triangle honor `hollow`; plus and cross
are stroked shapes. `pointSize` controls the marker diameter in pixels.

## Example

```cpp
#include <skigen/plot/plotview.h>
#include <Eigen/Core>
#include <QApplication>
#include <random>

int main(int argc, char* argv[]) {
    QApplication app(argc, argv);

    std::mt19937 rng(42);
    std::normal_distribution<float> dist(0.f, 1.f);

    int n = 200;
    Eigen::VectorXf x(n), y(n);
    for (int i = 0; i < n; ++i) {
        x(i) = dist(rng);
        y(i) = dist(rng);
    }

    Skigen::Plot::PlotView view;
    auto samples = view.scatter(
        x, y,
        {.color = Eigen::Vector4f{1.0f, 0.4f, 0.3f, 1.0f},
         .pointSize = 8.0f,
         .hollow = true,
         .label = "samples",
         .marker = Skigen::Plot::MarkerShape::Triangle});
    view.setLegendVisible(true);
    view.resize(600, 600);
    view.show();

    return app.exec();
}
```

## Use with Skigen ML

Scatter plots are ideal for visualizing ML results — cluster assignments, PCA projections, decision boundaries:

```cpp
// After PCA with Skigen
Skigen::PCA<double> pca(2);
Eigen::MatrixXd Z = pca.fit_transform(X);

view.scatter(Z.col(0).cast<float>(), Z.col(1).cast<float>());
```
